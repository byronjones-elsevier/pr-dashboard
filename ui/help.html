Help and overview

What this app does

Team PR Dashboard helps you quickly track open pull requests authored by the people or teams you care about, across your GitHub Enterprise or GitHub.com instance.

  • Fetch open PRs for selected users or imported teams.
  • Filter by title, repo, author, or “needs attention”.
  • Switch between list and card views.
  • Approve, close, or close-and-delete-branch directly from the UI.

Initial setup

When you first launch the app, it will prompt you to go to Settings. This is where you set up the connection to GitHub and the personal access token used for the API calls.

  1. Click the gear icon in the top-right corner.
  2. In Connections, enter your GitHub host, such as https://github.com or a GitHub Enterprise base URL.
  3. Paste a GitHub personal access token with the required repo access. The token is stored securely in the OS keychain when available.
  4. Set the API usage refresh interval if you want the quota countdown to update more or less often.
  5. Save your settings.

If the token is left blank, the app keeps the previously saved token. That makes it easy to update the host without losing the token.

Choosing users and groups

The left sidebar is the main selection area. It controls which authors the app queries for PRs. Nothing is fetched until at least one user or group is selected.

  • Individual users: add a GitHub username such as my-login.
  • Groups: add a team in the form org/team-slug. The app imports the current team roster from GitHub.
  • Use the checkboxes to toggle the users or groups currently included in the fetch.
  • Removing a group only stops tracking that group; it does not delete any other individual user tracking.

This means you can track a single developer, an entire team, or a mix of both, depending on how you want to monitor pull requests.

Fetching and reviewing pull requests

Once your GitHub connection is configured and at least one user/group is selected, click the Fetch button to load the open PRs that match your current selection.

  • The app shows PR age, repo, author, review status, and the date of the last activity.
  • Use the search box to filter PRs by title, repository, or author.
  • Enable Needs attention to focus on items that likely need action.
  • Use the list/card toggle to switch between a table and summary cards.

Using each section of the app

Sidebar

The sidebar is your query scope. It contains the tracked individuals and imported team groups. Checking a box tells the app to include that person or team in the next fetch.

Header actions

The top bar includes the main actions for the dashboard. Fetch reloads the selected PR list, while the Help menu contains the app help, version dialog, and GitHub repository link.

Toolbar

The toolbar lets you switch between list and card views, filter the active PR list, and use the export feature when you need to save a report.

Table / Card content area

This is where the open PRs appear. Each row or card shows the title, repo, author, review status, and age. Clicking a PR title opens the GitHub page in your browser, and action buttons let you approve or close PRs directly.

API usage box

The sidebar also shows Search API and Core API quota information. This helps you understand whether the app is approaching GitHub rate limits.

Review and action workflow

Each pull request has action buttons that let you quickly act on it without leaving the app:

  • Approve: leave a review comment and mark the PR as approved.
  • Open Review: opens the PR in GitHub.
  • Close: marks the PR as closed.
  • Close + delete branch: closes the PR and removes its head branch.
